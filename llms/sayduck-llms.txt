# Sayduck

> Sayduck is a 3D product visualization platform for ecommerce. Brands turn static
> product pages into interactive 3D configurators, WebAR try-in-your-space
> experiences, and virtual product photography. The integration surface is a
> browser-embedded Web Component (`<sayduck-viewer>`) with an in-page JavaScript
> API driven by DOM CustomEvents; the platform is backed internally by a GraphQL
> API. Founded 2012 (Niklas Slotte); independent since 2024 via The Optical
> Foundry.

## Integration model
- Embed: `<sayduck-viewer product="PRODUCT_UUID" mode="variants|configurator">` + `<script src="https://viewer.sayduck.com" type="module" async>`
- In-page API namespaces: variants, configurator, scene (materials, nodes, cameras, screenshots, WebAR), dynamic material, dynamic TRS, 3D text
- Handshake events: `sayduck.api-ready`, `sayduck.request-api`
- Identifiers: UUID per product/variant/configuration/material/node/camera/annotation
- Auth: viewer embeds a public product UUID (no API key); platform login is account-based
